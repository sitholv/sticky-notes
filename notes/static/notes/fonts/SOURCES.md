# Font sources

Instrument Sans (regular, medium, semibold) and Instrument Serif (regular)
are unmodified Google Fonts distributions, downloaded on 6 November 2026.

- https://fonts.google.com/specimen/Instrument+Sans
- https://fonts.google.com/specimen/Instrument+Serif
- https://github.com/google/fonts/tree/main/ofl/instrumentsans
- https://github.com/google/fonts/tree/main/ofl/instrumentserif

The accompanying OFL files contain the original copyright notices and
the full SIL Open Font License for each family.
